## 🛠️ ३. जुन्या टेस्ट स्क्रिप्ट्समधील असर्टेशन अंतर (Test Script Assertion Alignment Gap)

सध्या कोडमध्ये कोणताही दोष नसताना ३ जुन्या टेस्ट स्क्रिप्ट्स नापास होत आहेत, कारण त्यामधील चाचणीच्या अटी जुन्या आर्किटेक्चरवर आधारित आहेत:

1. **`test_rename_tool_33_e2e_matrix.js` (ओळ ४४३):**
   - *अंतर:* `assert.ok(data.forms['SWAYAM'])` तपासले जात आहे.
   - *आवश्यकता:* चेकपॉईंट CP-006 नंतर याचे नाव `SWAYAM DEENDAYAL YOJANA` झाले आहे. टेस्ट अटीमध्ये दोन्ही नावे स्वीकारणे आवश्यक आहे.
2. **`test_rename_settings_and_fuzzy.js` (ओळ ४८):**
   - *अंतर:* `assert.strictEqual(mahaDbt.length, 13)` तपासले जात आहे.
   - *आवश्यकता:* आता MAHA DBT मध्ये अधिकृत २८ दस्तऐवज असल्याने अट `assert.ok(mahaDbt.length >= 13)` अशी अद्ययावत हवी.
3. **`test_smart_auto_rename.js` (ओळ १०१):**
   - *अंतर:* जुने `btnReviewUnmatched` बटण शोधले जात आहे.
   - *आवश्यकता:* हे बटण UI क्लीनअपमध्ये काढले असून आता `Cross-Check Modal` वापरले जाते. चाचणीतून हे जुने चेक वगळणे आवश्यक आहे.
